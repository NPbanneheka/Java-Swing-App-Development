Default Admin Login:
Username: admin

How to run in VS Code / Terminal:
1. Extract the ZIP file.
2. Open the GateFlowPro_Desktop folder in VS Code.
3. Open Terminal.
4. Run:
   javac -encoding UTF-8 -d out src/com/gateflowpro/GateFlowPro.java
   java -cp out com.gateflowpro.GateFlowPro

Windows easy run:
- Double click run.bat

Important:
- This is a desktop application.
- Data is saved locally inside the data folder.
- No internet connection is required.
- User profile photos are copied to data/photos.

Modules included:
- Login
- User registration
- User profile and photo upload
- Gate pass issue
- Driver return / invoice seal verification
- Schedule issue
- Search records
- Reports and print
- User list
